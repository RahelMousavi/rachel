
# IoT Hacking Phases and Information Gathering

## 1. Introduction

IoT Hacking Methodology consists of several phases used to assess the security of IoT devices and systems.

The course identifies the following five phases:

1. Information Gathering
2. Vulnerability Scanning
3. Launch Attacks
4. Gain Remote Access
5. Maintain Access

## 2. Information Gathering

Information Gathering is the first phase of the IoT hacking methodology.

Its purpose is to collect information about IoT devices and the target environment before performing further security assessments.

The course introduces the following information-gathering topics:

### 2.1 Information Gathering Using Shodan

## 3. Authorized Testing

Information gathering should be performed only against devices and networks that you own or have explicit permission to assess.

The IoT hacking methodology consists of five phases:

1. Information Gathering
2. Vulnerability Scanning
3. Launch Attacks
4. Gain Remote Access
5. Maintain Access

Information gathering includes identifying IoT devices and collecting information using tools such as Shodan and MultiPing. The course also introduces discovering devices that use default credentials.
