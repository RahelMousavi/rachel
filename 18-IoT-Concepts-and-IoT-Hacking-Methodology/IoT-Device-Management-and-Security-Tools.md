
# IoT Device Management and Security Tools

## 1. Introduction

Managing and securing IoT devices requires appropriate platforms and security tools.

The course introduces two categories:

- IoT Device Management Tools
- IoT Security Tools

## 2. IoT Device Management Tools

IoT device management platforms help organizations manage and monitor connected devices and their associated services.

The following tools and platforms are listed in the course material.

### 2.1 Azure IoT Central

A Microsoft platform listed for IoT device management.

Official Website: [Azure IoT](https://azure.microsoft.com/en-us/products/iot)

### 2.2 Oracle IoT Asset Monitoring Cloud

An Oracle platform listed in the course for IoT asset monitoring and management.

### 2.3 Predix

An industrial IoT platform developed by GE.

### 2.4 Cloud IoT Core

Listed in the course as an IoT device management platform.

### 2.5 IBM Watson IoT Platform

An IBM IoT platform included in the course's device management tools.

### 2.6 AT&T IoT Platform

An IoT platform listed by the course for device management.

## 3. IoT Security Tools

The course lists the following tools and platforms for IoT security.

### 3.1 SeaCat.io

Listed as an IoT security solution.

### 3.2 DigiCert IoT Security Solutions

Security solutions for protecting connected devices and their communications.

Official Website: [DigiCert](https://www.digicert.com/)

### 3.3 FortiNAC

A network access control solution used to identify and manage devices connecting to a network.

Official Website: [Fortinet](https://www.fortinet.com/products/network-access-control)

### 3.4 Pulse: IoT Security Platform

Listed in the course as an IoT security platform.

### 3.5 Symantec IoT Security

An IoT security solution listed in the course material.

### 3.6 Darktrace

A cybersecurity platform that uses AI-based techniques for detecting potentially malicious activity.

Official Website: [Darktrace](https://www.darktrace.com/)

### 3.7 NSFOCUS ADS

An Anti-DDoS security solution listed in the course.

Official Website: [NSFOCUS](https://www.nsfocus.com/)

### 3.8 Barbara

Listed in the course as an IoT security solution.

### 3.9 Sternum

An IoT and embedded-device security solution.

Official Website: [Sternum](https://sternumiot.com/)
