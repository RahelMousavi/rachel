
# Web API and Web Service APIs

## 1. What Is a Web API?

A Web API (Web Application Programming Interface) is an interface that provides online web services to client-side applications.

It allows applications to retrieve and update data from different online sources.

Web APIs make online resources accessible and provide various tools, functions, and protocols that developers can use when building software and applications.

## 2. Web Service APIs

The module introduces five common types of Web Service APIs and related technologies:

- SOAP
- REST
- RESTful APIs
- XML-RPC
- JSON-RPC

### 2.1 SOAP

SOAP (Simple Object Access Protocol) is a web-based communication protocol that enables applications running on different platforms to communicate with each other.

It uses XML and HTTP to exchange information between systems.

For example, applications running on Windows and Linux can communicate through SOAP.

### 2.2 REST

REST (Representational State Transfer) is an architectural style for web services.

It is not a specific tool, feature, or framework. Instead, it defines an architectural approach for communication between different systems over the web.

### 2.3 RESTful APIs

RESTful APIs are designed according to REST principles and use HTTP as their communication protocol.

They commonly use the following HTTP methods:

- **GET:** Retrieve data from a resource.
- **POST:** Submit data to a resource.
- **PUT:** Create or update a resource.
- **DELETE:** Remove a resource.

### 2.4 XML-RPC

XML-RPC is a communication protocol that uses XML to encode and transfer data between systems.

Compared with SOAP, XML-RPC is simpler and uses less bandwidth for data transmission, according to the module.

### 2.5 JSON-RPC

JSON-RPC is a remote procedure call protocol that works similarly to XML-RPC.

The main difference is its data format:

- XML-RPC uses XML.
- JSON-RPC uses JSON.
