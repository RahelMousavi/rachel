## 2. Web Application Firewalls (WAF)

A Web Application Firewall (WAF) is a security solution designed to monitor and filter HTTP traffic between clients and web applications.

A WAF helps protect web applications against malicious requests and common web-based attacks.

It can inspect incoming traffic and apply security rules to identify and block suspicious requests.

## 3. Role of WAF in Web Application Security

A WAF provides an additional layer of protection between users and web applications.

Its main purposes include:

- Monitoring HTTP requests and responses.
- Filtering suspicious web traffic.
- Blocking requests that match malicious patterns.
- Helping protect applications against common web attacks.

A WAF should be considered an additional security layer rather than a replacement for secure application development and regular security testing.
