
# Executing Applications and Keyloggers

## Introduction to Executing Applications

**Executing Applications** is a stage in which an attacker runs programs on a target system after obtaining access to it.

In some penetration testing and hacking contexts, this stage is also referred to as **Owning the System**, because the attacker attempts to gain control over the target and perform actions through executed programs.

Depending on the attacker's objectives, these programs may include:

- Keyloggers
- Spyware
- Backdoors
- Malicious applications
- Remote access tools

The execution of unauthorized software can allow attackers to monitor user activity, collect sensitive information, or maintain access to a compromised system.

## Keyloggers

A **Keylogger** is a type of software or hardware designed to record keystrokes entered by a user.

Keyloggers can capture information such as:

- Usernames and passwords
- Messages and emails
- Search queries
- Other information typed using a keyboard

Keyloggers may operate without the user's knowledge, making them a serious privacy and security threat.

### Types of Keyloggers

Keyloggers are generally divided into two main categories:

### 1. Hardware Keyloggers

A **Hardware Keylogger** is a physical device that records keyboard input.

It is usually connected between a keyboard and a computer or integrated into a keyboard or another hardware component.

Common examples include:

- **PS/2 Keyloggers:** Devices connected through a PS/2 keyboard interface.
- **USB Keyloggers:** Small devices connected through a USB port.
- **Wi-Fi Keyloggers:** Devices that may transmit recorded keystrokes wirelessly.
- **Bluetooth Keyloggers:** Devices that use Bluetooth communication.
- **Embedded Keyloggers:** Keylogging components integrated into a keyboard or another hardware device.

Hardware keyloggers may be difficult to detect using traditional antivirus software because they operate outside the operating system.

### 2. Software Keyloggers

A **Software Keylogger** is a program that records keyboard input through software mechanisms.

It may run as a background process and store recorded information locally or transmit it to another system.

Software keyloggers may be distributed through:

- Malicious email attachments
- Infected software installers
- Malicious websites
- Exploited software vulnerabilities
- Other malware infections

Unlike hardware keyloggers, software keyloggers operate within the computer's software environment.

## Summary

Executing Applications refers to running programs on a target system after gaining access.

Keyloggers are tools designed to record keyboard input and may capture sensitive information such as passwords and private messages.

There are two main types:

- **Hardware Keyloggers:** Physical devices that record keyboard input.
- **Software Keyloggers:** Programs that monitor and record keyboard activity.

Both types can threaten user privacy and expose sensitive information.
