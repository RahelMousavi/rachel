
# Module 03: Network Scanning

## Overview of Network Scanning

Network Scanning is a collection of different processes used to identify hosts, ports, and services within a network.

It is an important part of information gathering because it helps create a profile and map of the target network.

## Main Objectives of Network Scanning

### 1. Identifying Live Hosts and Open Ports

Discovering accessible hosts within a network and identifying the open ports on those hosts.

### 2. Identifying Operating Systems and System Architecture

Determining the operating systems and architectures used by target systems.

### 3. Identifying Running Services

Discovering the services and applications running on target hosts.

### 4. Discovering Vulnerabilities

Identifying potential vulnerabilities and security weaknesses in target systems.

## Summary

Network Scanning is an information-gathering process used to discover hosts, open ports, running services, and potential vulnerabilities.

Its main purpose is to build a profile and map of the target network to support further security assessment.
