
# What Is Enumeration?

## Definition

Enumeration is the process of actively establishing a connection with a target system and sending different types of queries or requests to gather useful information.

During this phase, an attacker extracts information from the target system to prepare for further attacks, such as password attacks.

Unlike passive information gathering, Enumeration involves direct interaction with the target system.

## Sources of Enumeration

An attacker can collect information from several sources:

- **Network Resources and Shared Files:** Identifying shared folders, files, and available network resources.
- **Routing Tables:** Discovering network routes and understanding how different networks are connected.
- **Service Configurations:** Gathering information about running services and their configurations.
- **DNS and SNMP Details:** Collecting information about domain names, network devices, and their configurations.
- **Machine Names:** Identifying hostnames and computer names within the network.
- **Usernames and Groups:** Discovering user accounts and group memberships.
- **Banners and Applications:** Gathering information about running applications and services through their banners.

## Purpose of Enumeration

The main purpose of Enumeration is to collect detailed information about the target system and its network.

This information can help an attacker:

- Identify potential targets and entry points.
- Discover valid usernames and user groups.
- Find shared resources and network services.
- Prepare for subsequent attacks, such as password attacks.
