
# Android Trojans and Security

## 1. Types of Android Trojans

The course material introduces several Android Trojan families:

- Gustuff Banking Trojan
- xHelper
- Cerberus
- Boogr.gsh
- Asacub
- Gplayed
- HeroRat

These names are listed in the course material without further descriptions.

## 2. Securing Android Devices

The course material provides the following recommendations for improving Android device security.

### 2.1 Enable Screen Locks

Enable a screen lock to prevent unauthorized users from accessing the device.

### 2.2 Avoid Rooting

Avoid rooting Android devices because it can increase security risks.

### 2.3 Download Applications from Official Sources

Download applications only from official Android application marketplaces.

### 2.4 Use Security Protection

The course recommends using Android antivirus and protection applications, including Android Protector.

### 2.5 Keep the Operating System Updated

Install operating system updates whenever they become available.

Updates may include security improvements and fixes for known vulnerabilities.

## Summary

Android devices may be targeted by different Trojan families, including Gustuff, xHelper, Cerberus, Asacub, and others.

Important security recommendations include:

- Enabling screen locks.
- Avoiding root access.
- Installing applications from official marketplaces.
- Using security protection applications.
- Keeping the operating system updated.
