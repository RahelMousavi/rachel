
# General Mobile Platform Security Guidelines

## 1. Introduction

Mobile platform security guidelines provide recommendations for protecting mobile devices, applications, and sensitive information.

Following these guidelines helps reduce security risks and prevent unauthorized access to mobile device resources and data.

## 2. General Security Guidelines

### 2.1 Avoid Installing Too Many Applications

Avoid installing unnecessary applications on mobile devices to reduce potential security risks.

### 2.2 Disable Automatic Photo Uploads

Disable automatic photo uploads to social networks when they are not needed.

### 2.3 Assess Application Security

Perform a security assessment of an application's architecture before using it.

### 2.4 Maintain Device Configuration

Continuously maintain and monitor device configurations to ensure that security settings remain properly configured.

### 2.5 Use Trusted Application Stores

Install applications only from trusted and official application stores.

### 2.6 Securely Delete Device Data

Before selling or disposing of a mobile device, securely wipe or delete its stored data.

### 2.7 Control GPS Information Sharing

Share location information with GPS applications only when necessary.

### 2.8 Disable Unused Wireless Connections

Disable Wi-Fi and Bluetooth when they are not in use.

### 2.9 Avoid Simultaneous Network Connections

The course recommends avoiding simultaneous connections to two separate networks, such as Wi-Fi and Bluetooth.

### 2.10 Keep Software Updated

Regularly update the operating system and installed applications.

### 2.11 Avoid Rooting and Jailbreaking

Avoid rooting Android devices or jailbreaking iOS devices because these processes may weaken built-in security protections.

### 2.12 Back Up and Synchronize Data

Periodically back up and synchronize mobile device data to prevent data loss.

## Summary

General mobile platform security guidelines focus on reducing unnecessary exposure, protecting stored information, and maintaining secure device configurations.

Important recommendations include:

- Installing applications only from trusted stores.
- Updating the operating system and applications.
- Disabling unused Wi-Fi and Bluetooth connections.
- Avoiding rooting and jailbreaking.
- Controlling location information sharing.
- Securely wiping data before disposing of devices.
- Regularly backing up important information.
