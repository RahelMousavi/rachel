
# iOS Jailbreaking

## 1. What Is Jailbreaking?

Jailbreaking is the process of installing modified patches on the iOS kernel to remove restrictions imposed by Apple.

It allows users to gain additional control over their iOS devices and access features that are normally restricted.

### 1.1 Capabilities of Jailbreaking

Jailbreaking may allow users to:

- Install third-party applications that are not available through the App Store.
- Install additional plugins.
- Gain root-level access to the device.
- Bypass certain security restrictions, such as application sandboxing.

## 2. Types of iOS Jailbreaking

There are four main types of jailbreaking described in the course material.

### 2.1 Untethered Jailbreaking

An untethered jailbreak remains active even after the device is powered off and restarted.

The user does not need to repeat the jailbreaking process after every reboot.

### 2.2 Semi-tethered Jailbreaking

With a semi-tethered jailbreak, the jailbreak becomes disabled after restarting the device.

However, the device can still boot normally.

A computer is required to reactivate the jailbreak.

### 2.3 Tethered Jailbreaking

A tethered jailbreak requires a computer whenever the device restarts.

After a reboot, the device cannot boot normally without connecting it to a computer and performing the required jailbreak process.

### 2.4 Semi-untethered Jailbreaking

A semi-untethered jailbreak behaves similarly to a semi-tethered jailbreak.

However, the jailbreak can be reactivated using an application installed on the device without requiring a computer.

## Summary

Jailbreaking removes certain restrictions imposed by Apple by modifying the iOS kernel.

The four types of jailbreaking are:

- **Untethered:** Remains active after restarting the device.
- **Semi-tethered:** Device boots normally, but a computer is needed to reactivate the jailbreak.
- **Tethered:** Requires a computer to boot the device after restarting.
- **Semi-untethered:** Can be reactivated through an application on the device.
