
# Mobile Security Guidelines for Administrators

## 1. Introduction

Administrators are responsible for defining and enforcing security policies that control how mobile devices access organizational applications, systems, and data.

The course material highlights several administrative guidelines related to organizational policies and Access Gateway configurations.

## 2. Organizational Security Policies

### 2.1 Define Device Usage Policies

Publish an organizational policy that clearly defines the permitted use of personal and commercial mobile devices in the workplace.

### 2.2 Establish Cloud Policies

Create and communicate organizational cloud policies to employees.

### 2.3 Enable Security Measures

Enable appropriate security measures, such as antivirus and protection tools, to protect organizational data centers.

### 2.4 Define Access Permissions

Specify which applications and data employees are allowed or prohibited from accessing through personal devices.

## 3. Access Gateway Security Policies

An Access Gateway provides a controlled point through which users access organizational resources.

The course material identifies several security settings that administrators should define.

### 3.1 Session Timeout

Administrators should specify a Session Timeout policy through the Access Gateway.

A session timeout determines how long a user session can remain active before it expires.

### 3.2 Domain Password Policies

Administrators should decide whether the domain password is stored on the mobile device or whether users must enter it each time they access organizational resources.

## 4. Access Gateway Authentication Methods

The course material lists five authentication methods that administrators can configure.

### 4.1 No Authentication

No authentication is required before accessing the organizational resource.

### 4.2 Domain Only

Users authenticate using their domain credentials.

### 4.3 SMS Authentication

Users authenticate through an SMS-based verification mechanism.

### 4.4 RSA SecurID Only

Users authenticate using RSA SecurID.

### 4.5 Domain and RSA SecurID

Users must authenticate using both domain credentials and RSA SecurID.

## Summary

Administrators play an important role in securing mobile access to organizational resources.

Their responsibilities include:

- Defining mobile device usage policies.
- Establishing cloud security policies.
- Enforcing security measures.
- Controlling application and data access.
- Configuring session timeout policies.
- Defining domain password requirements.
- Selecting appropriate Access Gateway authentication methods.
