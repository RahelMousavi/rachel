# Diamond Model of Intrusion Analysis

## 1. Overview

The **Diamond Model of Intrusion Analysis** is a cybersecurity framework used to analyze cyberattacks and understand the relationships between attackers, their capabilities, infrastructure, and victims.
It helps security analysts investigate incidents, identify attack patterns, and gain a better understanding of adversary activities.
The model consists of four core features, represented as the four vertices of a diamond.

## 2. The Four Core Features

### 2.1 Adversary

**Adversary** refers to the individual, group, or organization responsible for conducting an attack.
This component focuses on identifying the attacker, their possible identity, motivations, and objectives.

### 2.2 Capability

**Capability** refers to the tools, skills, and techniques used by an attacker to conduct an attack.

**Examples:**

- Malware
- Exploits
- Phishing Techniques
- Attack Scripts

### 2.3 Infrastructure

**Infrastructure** refers to the resources and systems used by an attacker to conduct an attack or communicate with compromised systems.

**Examples:**

- Command and Control (C2) Servers
- Malicious IP Addresses
- Domains
- Compromised Servers

### 2.4 Victim

**Victim** refers to the individual, organization, system, or network targeted by an attacker.

**Examples:**

- Organizations
- Employees
- Computer Systems
- Network Devices

## 3. How the Diamond Model Works

The four components are connected and analyzed together to provide a better understanding of a cyberattack.
For example, when an organization is targeted:

- **Adversary:** The attacking group.
- **Capability:** The malware used in the attack.
- **Infrastructure:** The C2 server used by the malware.
- **Victim:** The targeted organization's network.

By examining these relationships, security analysts can gather additional information about the attacker and investigate related incidents.

## 4. Summary

The Diamond Model of Intrusion Analysis is used to investigate cyberattacks through four core features:

- **Adversary:** Who performs the attack?
- **Capability:** What tools and techniques are used?
- **Infrastructure:** What resources support the attack?
- **Victim:** Who or what is targeted?

Understanding these relationships helps security analysts investigate incidents, identify attackers, and connect related cyberattacks.
