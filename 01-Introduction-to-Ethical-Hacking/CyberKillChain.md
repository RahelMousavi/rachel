# Cyber Kill Chain

## 1. Overview

The **Cyber Kill Chain** is a cybersecurity model developed by Lockheed Martin to describe the different stages of a cyberattack.
It explains how attackers plan, prepare, and execute their attacks, from gathering information about a target to achieving their final objectives.
This model helps security professionals understand attacker behavior, identify malicious activities, and implement defensive measures at different stages of an attack.

## 2. Stages of the Cyber Kill Chain

The Lockheed Martin Cyber Kill Chain consists of seven stages:

### 2.1 Reconnaissance

**Reconnaissance** is the initial stage in which an attacker gathers information about the target before launching an attack.
The collected information may include:

- Target organization and employees.
- Network structure and IP addresses.
- Operating systems and applications.
- Potential vulnerabilities and security weaknesses.

The goal is to understand the target and identify possible attack opportunities.

### 2.2 Weaponization

**Weaponization** is the stage in which the attacker prepares a malicious tool or payload to exploit the target.
The attacker may combine an exploit with malware to create a weapon capable of compromising the target system.

**Common Examples:**

- Creating malicious files.
- Preparing malware.
- Combining an exploit with a malicious payload.

### 2.3 Delivery

**Delivery** refers to the process of transmitting the prepared malicious payload to the target.
The attacker uses different methods to deliver the payload to the victim.

**Common Examples:**

- Phishing emails.
- Malicious attachments.
- Compromised websites.
- Infected USB devices.

### 2.4 Exploitation

**Exploitation** occurs when the delivered payload takes advantage of a vulnerability in the target system or application.
This stage allows the attacker to execute malicious code or gain an initial foothold in the target environment.

### 2.5 Installation

During the **Installation** stage, the attacker installs malware or other malicious components on the compromised system.
The purpose is often to establish persistence and maintain access to the target.

**Common Examples:**

- Installing a backdoor.
- Deploying malware.
- Establishing persistent access.

### 2.6 Command and Control (C2)

**Command and Control (C2)** is the stage in which the compromised system establishes communication with infrastructure controlled by the attacker.
Through this communication channel, the attacker can remotely control the compromised system and send commands.

**Common Activities:**

- Sending commands to compromised systems.
- Receiving information from infected devices.
- Managing compromised systems remotely.
- Deploying additional malicious tools.

### 2.7 Actions on Objectives

**Actions on Objectives** is the final stage in which the attacker performs the intended malicious activities after gaining access to the target.

The attacker's objectives may include:

- Stealing sensitive information.
- Exfiltrating confidential data.
- Disrupting services.
- Destroying or modifying data.
- Deploying ransomware.
- Achieving financial or strategic goals.

## 3. Summary

The Cyber Kill Chain provides a structured model for understanding how cyberattacks are planned and executed.
The seven stages are:

1. Reconnaissance
2. Weaponization
3. Delivery
4. Exploitation
5. Installation
6. Command and Control (C2)
7. Actions on Objectives

Understanding these stages helps security professionals identify attack activities, detect intrusions, and prevent attackers from progressing through the attack lifecycle.
