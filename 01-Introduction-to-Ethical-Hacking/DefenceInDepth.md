# Defense-in-Depth

## 1. Overview

**Defense in Depth** is a cybersecurity strategy that uses multiple layers of security controls to protect an organization's systems, networks, and data.
Instead of relying on a single security mechanism, this approach combines several independent and complementary security layers.
The main goal is to ensure that if an attacker bypasses one security layer, additional layers can prevent further unauthorized access.
To reach sensitive organizational data, an attacker may encounter several layers of security controls.

## 2. Layers of Defense-in-Depth

### 2.1 Policies

Security policies define the rules, standards, and guidelines for protecting organizational resources.

**Examples:**

- Password Policies
- Access Control Policies
- Security Awareness Training
- Incident Response Policies

### 2.2 Physical

Physical security protects facilities, equipment, and infrastructure against unauthorized physical access.

**Examples:**

- Security Cameras
- Biometric Access Control
- Security Guards
- Locked Server Rooms

### 2.3 Perimeter

Perimeter security protects the organization's network boundary against external threats and controls incoming and outgoing traffic.

**Examples:**

- Firewalls
- Intrusion Prevention Systems (IPS)
- Network Gateways
- DMZ

### 2.4 Internal Network

Internal network security protects the organization's internal network against unauthorized access and the spread of attacks.

**Examples:**

- Network Segmentation
- Internal Firewalls
- Network Access Control (NAC)
- Intrusion Detection Systems (IDS)

### 2.5 Host

Host security protects operating systems, servers, and individual devices connected to the network.

**Examples:**

- Antivirus / EDR
- System Hardening
- Security Patching
- Host-based Firewalls

### 2.6 Application

Application security protects software and services against vulnerabilities and application-level attacks.

**Examples:**

- Secure Coding
- Input Validation
- Web Application Firewall (WAF)
- Authentication and Authorization

### 2.7 Data

Data security protects the organization's information and sensitive data from unauthorized access, modification, or disclosure.

**Examples:**

- Data Encryption
- Data Loss Prevention (DLP)
- Access Permissions
- Data Backup

## 3. Summary

Defense-in-Depth uses multiple layers of security controls to reduce the risk of unauthorized access and protect organizational assets.
Each layer provides an additional level of protection, ensuring that the failure of one security mechanism does not necessarily compromise the entire organization.

**Note:** These layers represent a conceptual security model, not a fixed sequence that every attacker must follow. Attackers may target different layers directly, depending on their access and attack methods.
