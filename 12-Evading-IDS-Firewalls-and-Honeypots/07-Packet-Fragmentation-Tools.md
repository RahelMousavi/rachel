
# Packet Fragmentation Tools

## Overview

Packet Fragmentation Tools are used to create, manipulate, and generate network packets. They can be used in network testing and security assessments to examine how network devices, firewalls, and IDS/IPS systems handle different packet structures.

## Packet Fragmentation Tools

The following tools are introduced in this section:

- **Colasoft Packet Builder**
- **CommView**
- **Hping3**
- **Multi-Generator**
- **Net Inspect**
- **Ostinato**
- **Fping3**
- **Net Scan Tools Pro**
- **Pktgen**
- **PACKETH**
- **Packet Generator**
