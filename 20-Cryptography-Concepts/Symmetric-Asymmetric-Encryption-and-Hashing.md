
# Encryption and Hashing

## 1. Symmetric Encryption Algorithms

Symmetric encryption is an encryption approach based on using a single key.

The same key is used for both encryption and decryption. Anything encrypted with a key can be decrypted using that same key.

## 3. Message Digest (One-Way Hash) Function

A Message Digest function, also known as a One-Way Hash Function, generates a fixed-size and unique bit string from an arbitrary block of information.

The resulting bit string is called a **Message Digest** or **Hash Value**.

### 3.1 Characteristics of Hash Functions

According to the module, hash functions have the following characteristics:

- **Fixed-size output:** A hash function produces a bit string with a fixed length, regardless of the size of the input data.
- **Sensitivity to input changes:** If even one bit of the input changes, there is approximately a 50% chance that each output bit will change.
- **Uniqueness:** It is computationally infeasible for two different files to produce exactly the same message digest.
- **One-way operation:** Hash functions are one-way functions. The original data cannot be recovered from the hash value.

### 3.2 Message Digest

A Message Digest is the fixed-size output generated by a hash function.

It represents the input information through a unique bit string. Even a small change in the original input can significantly affect the resulting digest.
