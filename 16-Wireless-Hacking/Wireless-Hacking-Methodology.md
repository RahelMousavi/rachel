
# Wireless Hacking Methodology

## Introduction

Wireless hacking methodology consists of several steps used to discover wireless networks, analyze wireless traffic, launch wireless attacks, and crack Wi-Fi encryption.

The module introduces four main steps:

## 1. Wi-Fi Discovery

The first step is discovering available wireless networks.

During this phase, wireless networks in the surrounding area are identified using Wi-Fi discovery tools.

The module introduces several tools for this purpose, including:

- Insider
- Net Surveyor
- Vistumbler
- NetStumbler
- WirelessMon
- Kismet
- WiFi Hopper
- Wave Stumbler
- iStumbler
- WiFinder
- Wellenreiter
- AirCheck WiFi Tester
- AirRadar 2
- Xirrus WiFi Inspector

## 2. Wireless Traffic Analysis

The second step is analyzing wireless network traffic.

Wireless traffic analysis tools are used to inspect and analyze wireless network communications.

The module introduces the following tools:

- Steel Central Packet Analyzer
- Sniffer Portable Professional Analyzer
- Capsa
- PRTG Network Monitor
- ApSniff
- NetworkMiner
- AirView
- Observer
- WiFi Scanner
- Mognet
- AirTraf

## 3. Launching Wireless Attacks

The third step involves launching wireless attacks.

The module introduces the Aircrack-ng Suite as a collection of tools used for wireless network discovery, packet sniffing, authentication cracking, and wireless network analysis.

### Aircrack-ng Suite

The suite includes several tools:

#### Aircrack-ng

Used to crack WEP, WPA, and WPA2 encryption.

#### Airodump-ng

Used to monitor wireless packets and frames.

#### Aireplay-ng

Used to generate wireless traffic, perform fake authentication, and send ARP packets.

#### Airmon-ng

Used to enable monitor mode on a wireless network interface.

## 4. Cracking Wi-Fi Encryption

The fourth step involves attempting to crack Wi-Fi encryption.

The module describes separate workflows for WEP and WPA/WPA2 networks.

These workflows are covered in the following files:

- WEP Encryption Cracking
- WPA/WPA2 Encryption Cracking

## Summary

The wireless hacking methodology introduced in this module consists of four main steps:

1. Wi-Fi Discovery
2. Wireless Traffic Analysis
3. Launching Wireless Attacks
4. Cracking Wi-Fi Encryption

Each step uses specific tools to identify wireless networks, inspect traffic, perform authorized security testing, and evaluate wireless encryption.
