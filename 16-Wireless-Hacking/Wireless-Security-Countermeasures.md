
# Wireless Security Countermeasures

## Introduction

Wireless networks require proper security configurations to reduce the risk of unauthorized access and wireless attacks.

The module introduces several configuration best practices for securing wireless networks.

## Wireless Configuration Best Practices

### 1. Change the Default SSID

Change the default SSID after setting up a Wireless LAN (WLAN).

Avoid using the company name, network name, or other obvious information as the SSID.

### 2. Disable Login and Remote Management

Disable login and remote management features on wireless devices when they are not required.

### 3. Protect Access to Wireless Devices

- Set a password to access the wireless device.
- Enable the firewall.

### 4. Enable MAC Filtering

Enable MAC filtering on the Access Point to control which devices can connect to the wireless network.

### 5. Disable SSID Broadcast

Disable SSID broadcasting on the Access Point.

### 6. Enable Wireless Encryption

Enable encryption on the Access Point and change the wireless network password periodically.

The module recommends using WPA instead of WEP.

### 7. Use Strong Passwords

Avoid using easily guessed passwords for wireless networks.

### 8. Limit Wireless Network Power

Limit the transmission power of the wireless network so that it cannot be identified outside the organization.

### 9. Implement Additional Traffic Encryption

Use additional encryption mechanisms, such as IPSec, over wireless networks.

### 10. Secure the Physical Location of Access Points

Place Access Points in secure locations to prevent unauthorized physical access.

### 11. Update Wireless Drivers

Keep the drivers of all wireless network equipment updated.

## Summary

The module recommends several practices to improve wireless network security:

- Change default SSIDs.
- Disable unnecessary login and remote management features.
- Protect wireless devices with passwords and firewalls.
- Enable MAC filtering.
- Disable SSID broadcasting.
- Enable wireless encryption and periodically change passwords.
- Avoid easily guessed SSIDs and passwords.
- Limit wireless transmission power.
- Use additional traffic encryption, such as IPSec.
- Secure the physical location of Access Points.
- Update wireless network drivers.
