
# Wireless Network Introduction

## Introduction to Wireless Networks

A wireless network is a type of computer network that allows devices to communicate and exchange data without using physical cables.

Wi-Fi is commonly used to connect devices such as computers, mobile phones, and game consoles to network resources through wireless communication.

Wireless networks are commonly used in environments where mobility, flexibility, and easy network access are important.

## Wireless Network Advantages

Wireless networks provide several advantages:

- **Quick and Easy Installation:** Wireless networks can be installed without the need to run physical cables.
- **Flexibility:** Networks can be expanded without being restricted by cabling limitations.
- **Mobility:** Users can access network resources from anywhere within the coverage range of an Access Point (AP).

## Wireless Network Disadvantages

Despite their advantages, wireless networks have some disadvantages:

- **Security:** Security is one of the biggest concerns in wireless networking.
- **Bandwidth:** Available bandwidth decreases as the number of connected systems increases.
- **Interference:** Electronic equipment in public places, such as airports, libraries, and schools, may interfere with Wi-Fi signals.

## Wireless Network Applications

Wireless networks can be used in different configurations and applications, including:

- Extending an existing wired network.
- Providing connectivity through 3G/4G hotspots.
- Connecting multiple Access Points.
- Establishing wireless LAN-to-LAN connections.

## Wireless Network Components

### Access Point (AP)

An Access Point is a device used to provide communication between wireless devices.

Wireless clients connect to an AP to access the wireless network.

### Hotspot

A hotspot is a location where a wireless network is publicly available.

### Association

Association is the process through which a wireless device connects to an Access Point.

### Basic Service Set Identifier (BSSID)

BSSID is the MAC address of an Access Point located within a Basic Service Set (BSS).

## Summary

Wireless networks provide connectivity without physical cables and allow users to access network resources within the coverage area of an Access Point.

Although they offer flexibility, mobility, and easier installation, they also introduce security concerns, bandwidth limitations, and possible signal interference.

Understanding wireless network components such as Access Points, hotspots, association, and BSSID is essential for studying wireless networking and security.
