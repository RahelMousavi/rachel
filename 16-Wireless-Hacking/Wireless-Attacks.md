
# Wireless Attacks

## Introduction to Wireless Attacks

Wireless networks can be exposed to different attacks because wireless communication takes place through radio signals.

Attackers may exploit insecure configurations or weaknesses in wireless network communication to gain unauthorized access or disrupt network connectivity.

## 1. Misconfigured Access Points

Access Points may be configured insecurely.

Common examples include:

- Access Points commonly broadcast their SSID.
- Administrators may mistakenly use the SSID as the password for user convenience.
- An attacker may easily connect to the wireless network and perform further actions.

Using insecure configurations can expose a wireless network to unauthorized access.

## 2. Wireless Denial-of-Service (DoS)

A Wireless Denial-of-Service attack attempts to disconnect a device from a wireless network.

According to the module, an attacker sends De-Authentication packets to force a wireless client to disconnect from the network.

The purpose of this attack is to interrupt wireless connectivity.

## 3. Wireless Jamming

Wireless Jamming is listed in the module as a type of wireless attack.

The PDF introduces this attack by name but does not provide further technical details.

## 4. MAC Address Spoofing

MAC Address Spoofing involves changing the attacker's MAC address to match the MAC address of an authenticated device.

This technique can be used to bypass MAC filtering configured on an Access Point.

## Summary

The wireless attacks introduced in this module include:

- **Misconfigured Access Points:** Exploiting insecure Access Point configurations.
- **Wireless DoS:** Sending De-Authentication packets to disconnect wireless clients.
- **Wireless Jamming:** Introduced as a wireless attack, without further explanation in the PDF.
- **MAC Address Spoofing:** Changing a device's MAC address to bypass MAC filtering.
