
# Wireless Security Tools

## Introduction

The module introduces tools and platforms used to improve wireless network security, deploy Wireless Intrusion Prevention Systems, and audit wireless networks.

## Wireless Intrusion Prevention Systems (WIPS)

Wireless Intrusion Prevention Systems are introduced as a category of wireless security solutions.

The module lists the following WIPS products and platforms:

- Extreme Networks IPS
- AirMagnet Enterprise
- Dell SonicWall Clean Wireless
- HP TippingPoint NX Platform NGIPS
- AirTight WIPS
- Network Box IDP
- AirMobile Server
- Wireless Policy Manager
- FortiWiFi

## Wi-Fi Security Auditing Tools

The module introduces the following tools and platforms for Wi-Fi security auditing:

- AirMagnet WiFi Analyzer
- AirDefense Services Platform
- Adaptive Wireless IPS
- Aruba RFProtect

## Summary

The module introduces wireless security tools in two categories:

- **Wireless Intrusion Prevention Systems (WIPS):** Products and platforms listed for wireless intrusion prevention.
- **Wi-Fi Security Auditing Tools:** Tools and platforms listed for auditing wireless network security.
