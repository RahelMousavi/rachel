
# Beacon Frames and Wireless Security

## Beacon Frames

Access Points periodically transmit Beacon frames into their surrounding area.

According to the module, APs send Beacon frames approximately 10 to 100 times per second.

A wireless station that wants to join a network may receive a Beacon frame and then send an Association Request to the Access Point.

## Wireless Security Protocols

Wireless networks use different security protocols and encryption mechanisms to protect wireless communication.

### 1. Wired Equivalent Privacy (WEP)

WEP is an older wireless security algorithm.

According to the module, WEP can be easily broken.

### 2. Wi-Fi Protected Access (WPA)

WPA is an advanced wireless encryption algorithm.

The module identifies AES and TKIP as encryption mechanisms used with WPA.

### 3. Wi-Fi Protected Access 2 (WPA2)

WPA2 is an advanced version of WPA.

According to the module, WPA2 uses 128-bit AES and CCMP.

### 4. WPA2 Enterprise

WPA2 Enterprise uses a separate authentication system called RADIUS.

### 5. Advanced Encryption Standard (AES)

AES is a symmetric-key encryption algorithm used in WPA2.

The module also identifies AES as a replacement for TKIP.

### 6. Temporal Key Integrity Protocol (TKIP)

TKIP is a security protocol used in WPA.

It was introduced as a replacement for WEP.

### 7. IEEE 802.11i

IEEE 802.11i is a standard that defines security mechanisms for IEEE 802.11 wireless networks.

### 8. Lightweight Extensible Authentication Protocol (LEAP)

LEAP is a wireless authentication protocol designed for Cisco devices.

## Summary

Beacon frames are periodically transmitted by Access Points to announce their presence to nearby wireless stations.

Wireless security protocols and mechanisms introduced in this module include:

- WEP
- WPA
- WPA2
- WPA2 Enterprise
- AES
- TKIP
- IEEE 802.11i
- LEAP
