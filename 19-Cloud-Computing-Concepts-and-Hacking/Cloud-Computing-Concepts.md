
# Cloud Computing Concepts

## 1. Introduction to Cloud Computing

Cloud Computing is a computing model that provides IT capabilities and infrastructure to customers as services.

The services provided depend on the customer's requirements and the amount of resources they pay for.

Major cloud service providers include:

- Google
- Amazon
- Microsoft

## 2. Characteristics of Cloud Computing

The course identifies the following characteristics of cloud computing:

### 2.1 On-Demand Self-Service

Cloud resources can be accessed and provisioned without requiring the direct presence of an administrator or service provider.

### 2.2 Broad Network Access

Cloud services are available over a network and can be accessed through different devices.

### 2.3 Resource Pooling

Cloud providers maintain a collection of resources that can be allocated to customers according to their requirements.

### 2.4 Rapid Elasticity

Cloud resources can be expanded according to customer requirements.

### 2.5 High Speed and Availability

Cloud services provide high-speed capabilities and service delivery.

### 2.6 Automated Management

Cloud environments support automated management of resources and services.

## 3. Cloud Computing Service Models

Cloud computing services are categorized into different models based on the type of resources and services provided.

### 3.1 Infrastructure as a Service (IaaS)

IaaS provides infrastructure resources such as virtual machines and other required hardware and software.

Customers can use these resources to deploy operating systems and applications.

Examples:

- Amazon Web Services (AWS)
- ArvanCloud

### 3.2 Platform as a Service (PaaS)

PaaS allows customers to deploy and run their applications and services on cloud infrastructure.

Examples:

- Google App Engine
- Microsoft Azure

### 3.3 Software as a Service (SaaS)

SaaS provides applications that run on cloud infrastructure and are accessible to customers through client applications.

Examples:

- Google Docs
- Web-based Microsoft Office

### 3.4 Identity as a Service (IDaaS)

IDaaS provides identity and access management services through a third-party provider.

These services may include:

- Single Sign-On (SSO)
- Multi-Factor Authentication (MFA)

Examples:

- OneLogin
- Microsoft Azure Active Directory
- Okta

### 3.5 Security as a Service (SECaaS)

SECaaS integrates security services into an organization's infrastructure through a cloud-based service model.

It is based on the SaaS model and can provide services such as:

- Penetration Testing
- Authentication
- Intrusion Detection
- Security Incident Management

## 5. Cloud Deployment Models

Cloud deployment models are selected according to organizational requirements.

The course introduces four deployment models.

### 5.1 Private Cloud

A Private Cloud is a cloud infrastructure dedicated to a single organization.

It can be located either inside or outside the organization's premises.

### 5.2 Community Cloud

A Community Cloud is shared by multiple organizations that have common requirements or objectives.

It supports a specific group of organizations with shared responsibilities.

### 5.3 Hybrid Cloud

A Hybrid Cloud combines two or more cloud environments, such as:

- Private Cloud
- Community Cloud
- Public Cloud

Each environment maintains its unique characteristics while being connected through standardized or proprietary technologies.

### 5.4 Public Cloud

A Public Cloud provides cloud services that are available to a large group of customers.

## Summary

Cloud Computing provides IT infrastructure and capabilities as services over a network.

Its main characteristics include on-demand self-service, broad network access, resource pooling, rapid elasticity, high-speed service delivery, and automated management.

The five service models covered in this section are:

1. Infrastructure as a Service (IaaS)
2. Platform as a Service (PaaS)
3. Software as a Service (SaaS)
4. Identity as a Service (IDaaS)
5. Security as a Service (SECaaS)

The four deployment models are Private Cloud, Community Cloud, Hybrid Cloud, and Public Cloud.

Major cloud providers include Microsoft Azure, Amazon Web Services, Google Cloud Platform, and IBM Cloud.
