
# Module 19: Cloud Computing Concepts and Hacking

## Overview

Cloud Computing is a model of computing that provides IT capabilities and infrastructure to customers as services.

This module explores cloud computing concepts, service and deployment models, container technology, cloud security threats, common attacks, hacking tools, and security countermeasures.

It also introduces technologies such as Docker and Kubernetes and discusses security risks associated with cloud environments and containerized applications.

## Learning Objectives

After completing this module, you should be able to:

- Understand cloud computing concepts and characteristics.
- Identify different cloud service and deployment models.
- Recognize major cloud service providers.
- Understand container technology and its architecture.
- Explain the differences between containers and virtual machines.
- Understand Docker and Kubernetes.
- Identify common cloud and Kubernetes security risks.
- Recognize cloud computing threats and attack techniques.
- Understand Man-in-the-Cloud (MITC) attacks.
- Identify tools used for cloud hacking and security assessment.
- Understand cloud security control layers.
- Apply cloud security best practices and countermeasures.
