
# Followerwonk

[Followerwonk](https://followerwonk.com/) is a social media analysis tool designed to search and analyze Twitter (X) profiles and their followers.

It can help researchers discover information about social media users, compare accounts, and analyze follower relationships.

## Main Features

### 1. Search Bios
Allows users to search Twitter profiles based on keywords and information available in their biographies.

### 2. Compare Users
Helps compare different Twitter accounts and analyze their followers and social media presence.

### 3. Analyze
Provides information and statistics about Twitter profiles and their activity.

### 4. Track Followers
Allows users to track changes in an account's followers.

### 5. Sort Followers
Helps organize and analyze followers based on available profile information and metrics.

## Information Available

According to the interface shown in the course material, Followerwonk can display information such as:

- **Screen Name:** The user's Twitter username.
- **Real Name:** The name associated with the profile.
- **Location:** The location listed in the user's profile.
- **Tweets:** The number of published tweets.
- **Following:** The number of accounts followed by the user.
- **Followers:** The number of followers.
- **Account Age:** How long the account has existed.
- **Social Authority:** A metric used to estimate a profile's social influence.

## Role in Footprinting

Followerwonk can help security researchers:

- Discover publicly available social media profiles.
- Identify employees and other accounts associated with an organization.
- Analyze relationships between social media accounts.
- Examine follower networks and social influence.
- Collect publicly available information for OSINT investigations.
