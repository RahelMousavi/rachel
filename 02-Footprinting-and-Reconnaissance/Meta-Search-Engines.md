
# Gathering Information from Meta Search Engines

Meta search engines are tools that collect search results from multiple search engines and combine them into a single list.
They help security researchers discover information from different sources without having to search each engine separately.
During the Footprinting phase, these tools can be used to gather publicly available information about a target, such as websites, documents, domains, and other online resources.

## 1. Startpage

[Startpage](https://www.startpage.com/) is a privacy-focused search engine that provides web search results while protecting users' personal information.

It acts as an intermediary between users and other search providers, including Google and Bing, and returns search results without personalizing them based on users' search history.

### Main Features

- **Private Search:** Does not store users' personal search history or build profiles based on their searches.
- **Unprofiled Results:** Provides search results without personalization based on previous browsing activity.
- **Multiple Search Sources:** Uses search technology from providers such as Google and Bing.
- **Anonymous View:** Allows users to visit websites through Startpage's proxy, helping hide their IP address from the destination website.
- **Web and Image Search:** Supports searching for websites, images, videos, and news.

### Role in Footprinting

Startpage can help security researchers discover publicly available information about a target, including:

- Public websites and web pages.
- Documents and files indexed by search engines.
- Information about an organization and its online presence.
- Publicly available technical information.

**Official Website:** https://www.startpage.com/

## 2. MetaGer

[MetaGer](https://metager.org/) is a privacy-focused metasearch engine developed and operated by the German nonprofit organization SUMA-EV.
It combines search results from multiple search engines and ranks them using its own algorithms.
Unlike traditional search engines, MetaGer primarily relies on external search indexes rather than maintaining a large independent web index.

### Main Features

- **Metasearch:** Combines results from multiple search engines into a single list.
- **Privacy Protection:** Designed to minimize tracking and the collection of personal information.
- **Open Source:** Its source code and ranking algorithms are publicly available.
- **Anonymous Browsing:** Provides an anonymous proxy feature for visiting websites.
- **Multiple Search Categories:** Supports different types of searches, including web pages, images, news, and other resources.

### Role in Footprinting

MetaGer can help security researchers collect information from multiple search sources, including:

- Public websites related to a target.
- Documents and publicly indexed files.
- Information about organizations and their online presence.
- Additional search results that may not appear in other search engines.

**Official Website:** https://metager.org/

## Summary

Meta search engines are useful during the Footprinting phase because they combine results from different search providers.

- **Startpage:** Focuses on private searching and provides results from providers such as Google and Bing.
- **MetaGer:** Combines results from multiple search engines and ranks them using its own algorithms.

Both tools can help security researchers discover publicly available information while reducing the need to search multiple platforms separately.
