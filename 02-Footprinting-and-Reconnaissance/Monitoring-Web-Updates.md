
# Monitoring Web Updates

Monitoring Web Updates is a technique used to automatically detect changes and updates on websites.

Tools such as Website Watcher allow users to monitor web pages and receive notifications when their content changes.

## Main Purpose

Website monitoring helps researchers:

- Detect changes in website content.
- Identify newly published information.
- Monitor updates to specific web pages.
- Track changes in an organization's online presence.
- Stay informed about website modifications.

## Website Monitoring Tools

The following tools are introduced in the course material:

### 1. ChangeDetection

A website monitoring service that detects changes in web page content and notifies users.

Website: https://changedetection.io/

### 2. OnWebChange

A service designed to monitor web pages and notify users when selected content changes.

Website: https://onwebchange.com/

### 3. Follow That Page

A website monitoring service that tracks web page changes and sends notifications.

Website: https://www.followthatpage.com/

### 4. Infominder

A website monitoring tool historically used to track changes in web pages.

### 5. Page2RSS

A service that converts web page updates into RSS feeds, allowing users to follow changes through an RSS reader.

### 6. Tracked Content

A website monitoring service listed in the course material for tracking changes to online content.

## Website Watcher

Website Watcher is a tool mentioned in the course material for automatically monitoring website updates and modifications.

It helps users track changes without manually checking websites repeatedly.

## Role in Footprinting

Monitoring Web Updates can help security researchers:

- Track changes to an organization's website.
- Discover newly published pages and information.
- Monitor changes in publicly available services and content.
- Identify modifications to organizational announcements.
- Keep reconnaissance information up to date.

## Summary

Monitoring Web Updates involves automatically tracking website changes using specialized tools.

During Footprinting, it helps researchers identify new information, monitor organizational websites, and keep collected OSINT data up to date.
